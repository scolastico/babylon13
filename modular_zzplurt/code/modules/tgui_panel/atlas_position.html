modular_zzplurt/code/modules/tgui_panel/atlas_position.dm

/proc/atlas_station_zThe atlas's z for a world z: the 1-based index among the station's levels (SSmapping.levels_by_trait(ZTRAIT_STATION)), or null off the station (CentCom, lavaland, space ruins, reserved levels). Shared by the position updates and the stat panel's map link (client_procs.dm "openWebMap"), so both use the same frame on every map, multi-z or not.
/proc/atlas_map_urlThe current map's atlas URL (maps.txt webmap_url), or null when it has none.
/proc/atlas_map_linkThe stat panel's map link to a tile: the map's atlas URL with "t=x,y,z" (z within the station) in its fragment, or the plain URL off the station. A URL without a "#" fragment (an older webmap_url such as ".../metastation/") gets one. Null when the map has no atlas URL.
/proc/atlas_map_keyThe atlas's key of the current map: the "m" parameter of its webmap_url fragment (maps.txt, e.g. ".../splurt-atlas/#m=metastation" gives "metastation"), the same key the stat panel's map link opens. Null when the map has no such URL.
/proc/atlas_positions_enabledPosition updates run: they are not switched off (interval 0) and the map is one the atlas has (a webmap_url in maps.txt). Other maps report nothing.
