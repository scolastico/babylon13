/proc/babylon_supervisor_requestBlocks until the supervisor answers (world.Export has no timeout): only /datum/babylon_supervisor_call calls it. Everything else uses babylon_supervisor_request_within() (test_contracts.py checks this).
/datum/babylon_supervisor_callOne supervisor request run in the background (babylon_supervisor_request_within()).
/proc/babylon_supervisor_request_withinbabylon_supervisor_request(), but waits at most timeout deciseconds. world.Export has no timeout of its own: the request goes on in the background, and on_answer is called with its answer whenever it arrives. Returns the answer, or list("ok" = FALSE, "error" = ..., "timeout" = TRUE). Sleeps: call it from a background proc (INVOKE_ASYNC), never from a ui_act. call_type: tests put in a call that answers late.
/proc/babylon_stop_messageThe chat line players see when the world stops; says truthfully whether it is saved.
