/proc/babylon_creative_spawn_rootsEverything a creative player can spawn is one of these (or a subtype).
/proc/babylon_creative_spawn_blockedTRUE when a creative player may not spawn this path. The blacklist:
/proc/babylon_creative_type_harmfulThe "harmful" half of babylon_creative_spawn_blocked(): what may not exist in a world because of what it does (the blocked roots, ERP, debug/admin tools, builder drones, test humans, the circuit board of anything harmful). Checks of things that come inside another item (the creative disposal unit's contents check) use only this half: a revolver's internal cylinder or an implanter's implant is no spawnable entry of its own, but harmless where its item puts it.
/proc/babylon_creative_not_an_entryThe "not a spawnable entry" half of babylon_creative_spawn_blocked(): outside babylon_creative_spawn_roots(), abstract types, types without a name or icon, ABSTRACT items, and the circuit board of a machine that is no entry itself.
BABYLON_CREATIVE_MOB_CAPLiving mobs spawned from Creative panels in this world at most (all players together).
/proc/babylon_creative_living_mobsHow many creative-spawned mobs are still alive (dead and deleted ones are pruned).
/proc/babylon_creative_entryOne spawnable type as the panel shows it.
/proc/babylon_creative_categoriesThe Spawn tab's curated categories: list of list(id, name, icon, entries).
/proc/babylon_creative_category_rootWhich root a search category limits the search to; "all" (or anything unknown) searches every root.
/proc/babylon_creative_category_idsEvery category id the panel can search in ("all" plus babylon_creative_categories()).
/proc/babylon_creative_indexEvery spawnable type, built once: list of list(path, lowercase name, lowercase path text).
/proc/babylon_creative_search_aliasesWords players use for things that are named differently in game: query => extra queries.
/proc/babylon_creative_searchThe search: exact names first, then names starting with the query, names containing it and type paths containing it; aliases (babylon_creative_search_aliases) search too. Returns list("results" = entries, at most BABYLON_CREATIVE_SEARCH_LIMIT, "capped" = more matched).
/proc/babylon_creative_disambiguateEntries sharing a name get a "hint": the end of their type path ("full"), or "standard" for the base type of a same-named subtype.
/proc/babylon_creative_spawnCreates path for user: one stack of amount (clamped to the stack's maximum), or amount copies (1 to BABYLON_CREATIVE_MAX_COPIES) of anything else, at the user's feet or, for items with in_hand, in their hands. Returns the created atoms, or an error text.
