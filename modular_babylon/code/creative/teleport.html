modular_babylon/code/creative/teleport.dm

/proc/babylon_creative_level_allowedTRUE when z is one of this world's real levels.
/proc/babylon_creative_levelsThe levels a creative player can teleport to: list of list(z, name).
/proc/babylon_creative_areasThe areas on this world's levels (space left out): list of list(path, name, z), by name.
/proc/babylon_creative_playersThe other players in this world a creative player can teleport to: list of list(ckey, name).
/proc/babylon_creative_markersThe tutorial markers a creative player can teleport to: list of list(id, x, y, z).
/proc/babylon_creative_teleportMoves user to destination, or the nearest free spot if it is blocked and the user has no noclip. Returns null on success, else the reason.
/proc/babylon_creative_coordinates_turfCoordinates from the panel, clamped to the map; the level must be one of this world's.
/proc/babylon_creative_area_turfA free turf in an area, on this world's levels (on level only_z when it is given), or null.
