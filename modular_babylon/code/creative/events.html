/proc/babylon_creative_eventsThe events the panel offers: list of list(path, name, description, category), by name.
/proc/babylon_creative_run_eventStarts an event from the panel. Returns the round event, or an error text.
/proc/babylon_creative_event_controlThe event control of an offered event (babylon_creative_events), or null when it is unknown or refused (babylon_creative_event_blocked).
/proc/babylon_creative_event_allowedWhether the Events tab offers this event (also what a tutorial's Start event action may start).
/proc/babylon_creative_start_eventStarts an offered event, the one way every Babylon feature starts one (the Creative panel's Events tab, the tutorial's Start event action). Returns the round event, or an error text. Started events are listed in GLOB.babylon_creative_events: they are stepped where SSevents does not run (babylon_creative_step_events) and ended when Creative is switched off.
/proc/babylon_creative_end_eventsEnds every event started from a Creative panel that is still running. Events that already started get their end() first, which undoes their effects (wormholes, surge values, traits).
/proc/babylon_creative_events_need_steppingEvents need SSevents to step them; the Babylon build switches it off (rules.dm).
