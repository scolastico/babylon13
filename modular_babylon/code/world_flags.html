/tg/ Station 13 - Modules - Types

modular_babylon/code/world_flags.dm

/proc/babylon_param_flag"1"/"0" world parameters; anything else (or none) is the default.
/proc/babylon_safe_idCatalog and tutorial ids: letters, digits, _ and -, at most 64 characters.
/proc/babylon_is_station_buildThis process is the station build (babylon-station.dme).
/proc/babylon_world_saves_charactersThe policy table's saves_characters(), and never for a forced tutorial snapshot (for_tutorial: a submission or save-back, from any world): the one rule for "tutorial snapshots carry no characters". The supervisor's copy is world_policy()["saves_characters"] (constants.py), and tutorials.py blanks them again in every snapshot it copies.
/proc/babylon_world_readyThe world can admit players and answer the supervisor's status as ready: the session's own ready flag, which also lets it save. Reporting ready before that flag was set (up to a second later on station worlds) made a stop right after the start skip its save as "not finished starting", and the smoke's ready check fail now and then.
