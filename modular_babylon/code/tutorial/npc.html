/tg/ Station 13 - Modules - Types

modular_babylon/code/tutorial/npc.dm

/proc/babylon_tutorial_skip_saveAtoms a checkpoint must not save: tutorial NPCs, everything they carry and their outfit's items wherever they are. The checkpoint asks every atom through babylon_skip_save() (persistence.dm), which is wired to this below.
/proc/babylon_tutorial_awakeAwake: alive, not in crit, not unconscious or asleep.
/proc/babylon_tutorial_kill_quietlyA corpse from the start: dead without a death gasp in chat (it was never seen alive); no rot (attach_rot below).
/proc/babylon_tutorial_anchor_npcSticks a tutorial NPC in place (spec 12 #4), with the game's own flags and traits:
/proc/babylon_tutorial_effect_kindsEffect kind => label, for the configure window.
/proc/babylon_tutorial_woundsWound path => label: the wounds a tutorial NPC can have.
/proc/babylon_tutorial_diseasesDisease path => label: illnesses a tutorial NPC can have (not contagious to the world's machinery; ordinary curable diseases).
/proc/babylon_tutorial_blood_reagentsReagent path => label: what can be in a tutorial NPC's blood (medicine, common poisons and a few drugs a medical tutorial needs). Nothing that transforms, spreads or harms the world.
/proc/babylon_tutorial_outfit_optionsThe outfits offered first (any job outfit can also be searched).
/proc/babylon_tutorial_clean_effectsValidates an effects list: list(list(kind, amount, zone, type, chance), ...).
/proc/babylon_tutorial_apply_effectsApplies effects to an NPC, each with its chance. Returns the kinds that were applied.
/datum/babylon_tutorial_npc_moveOne NPC walking to a tile for a Move NPC action: a step every move delay along a JPS path (get_path_to, the game's pathfinder, the same one AI mobs use), found again when the way is blocked. Crawls when the NPC can't stand (a lying mob moves, only slower). Ends on arrival (the action's On arrival actions run), or gives up at the deadline (a note for the builder).
/proc/babylon_tutorial_npc_accessThe access an NPC's path is found with. "id": its ID card's (none without a card); "public": none, so only doors anyone may open; "all": every access (the walk opens the doors itself).
/proc/babylon_tutorial_npc_step_delayDeciseconds between two steps: the NPC's own move speed (slower when it crawls or is hurt), at least a brisk walk, at most two seconds.
/proc/babylon_tutorial_npc_presetsPreset id => list(name, desc, icon, settings): ready-made NPC spawners.
/proc/babylon_tutorial_place_npcPlaces an NPC spawner from a preset on a tile and creates its NPC. Returns the spawner.
