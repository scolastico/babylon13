modular_babylon/code/tutorial/players.dm

/proc/babylon_tutorial_player_keyThe key the run knows a mob's player by.
/proc/babylon_tutorial_can_playA mob that can take part in the run: living, not a tutorial NPC.
/proc/babylon_tutorial_ghosts_by_keyckey => ghost, for ghosts that carry a key.
/proc/babylon_tutorial_mob_of_keyThe mob that holds a player key now (their client's mob, else a ghost carrying the key).
/proc/babylon_tutorial_put_player_inPuts a player (by key) back into a body: their ghost's key (and mind) move into it. Only from a ghost or a dead body: a player in the lobby or in another living body is left alone.
/proc/babylon_tutorial_revive_slotsThe slots a revive dresses, uniform first (pockets, belt and ID hang on it).
/proc/babylon_tutorial_capture_itemsWhat a human wears, holds and carries in its backpack: list(list(type, slot, hand, packed, item weakref)). Not copy_outfit(): that admin helper asks for a name and registers globally.
/proc/babylon_tutorial_restore_itemsDresses a rebuilt body. Per item: the original when it still exists and no one carries it (dropped by a gib, lying on the floor or in a crate); nothing when someone else carries it now; a fresh copy only when it is gone.
/proc/babylon_apply_identitySpecies, DNA, name, blood type and look from a babylon_capture_identity() list (or a saved character entry, which holds the same keys).
