/tg/ Station 13 - Modules - Types

modular_babylon/code/tutorial/wand.dm

/proc/babylon_tutorial_wand_typeThe tutorial wand's type (the Creative panel hands it out).
/proc/babylon_tutorial_category_colorsCategory => label colour of the wand's images and windows.
/proc/babylon_tutorial_wand_modesThe wand's modes, in the order right-clicking cycles through them.
/proc/babylon_tutorial_placePlaces a tutorial object of a type. A new trigger after the first starts listening after the most recently placed trigger, so steps chain in placing order (builders can change it).
/proc/babylon_tutorial_repositionMoves a tutorial object to a tile (an NPC spawner with its NPC). Everything else about it stays.
/proc/babylon_tutorial_view_keyWhose view a mob's wand shows: the player's ckey (a ref for a mob without one).
/proc/babylon_tutorial_view_groupThe view group of an object: "marker", "trigger", "gate", "action" or "npc".
/proc/babylon_tutorial_view_groupsThe view groups, in the Overview's order.
/proc/babylon_tutorial_view_group_membersEvery placed object of a view group.
/proc/babylon_tutorial_set_hiddenHides or shows objects in one builder's view; that builder's wands redraw.
/proc/babylon_tutorial_forget_hiddenA deleted object leaves every builder's hidden list.
/proc/babylon_tutorial_hidden_countHow many placed objects a builder has hidden.
/proc/babylon_tutorial_cached_searchType search results, cached per base and query (the last 50 queries).
/proc/babylon_tutorial_tell_playersTells every player of the run but the builder what happened to the run.
/proc/babylon_tutorial_follow_upsThe follow-up actions an action runs itself (a Move NPC action's On arrival), for the Flow.
/proc/babylon_tutorial_event_optionsThe events a Start event action offers (the Creative panel's list), for its window; empty for every other kind (the list is long).
