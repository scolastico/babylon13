/tg/ Station 13 - Modules - Types

modular_babylon/code/tutorial/runtime.dm

/proc/babylon_tutorial_current_runThe world's tutorial run, if the tutorial is running.
/proc/babylon_tutorial_beginStarts (or restarts) the world's tutorial run. from_start: every living player moves to the "start" marker first. test_run: a builder's test (the completion screen offers no lobby button). reset_npcs: spawn-at-start NPCs are created again, fresh (a test restart). players: mobs that take part from the first step even without a client (the spawning player, tests).
/proc/babylon_tutorial_player_spawnedA player spawned in a tutorial world: the run starts with them, or they join the running one.
/proc/babylon_tutorial_endStops the world's run, if any.
/proc/babylon_tutorial_marker_turfThe turf of the marker with this id (players start at "start").
/proc/babylon_tutorial_spawn_start_npcsNPC spawners set to spawn at the start create their NPC: those without one, or all of them again when reset.
/proc/babylon_tutorial_triggers_afterThe triggers that start listening when this trigger fires ("After fired").
/proc/babylon_tutorial_look_signalsSignals after which an atom may look different (an NPC turns, lies down, takes something).
/atom/movable/screen/alert/babylon_tutorial_objectiveThe objective alert: an icon with the objective written next to it.
