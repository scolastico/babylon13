modular_babylon/connection.dm

/proc/babylon_connection_addressRoute default loopback links through the server the player actually reached. winget's "url" is the SERVER's IP:port; client.address is the PLAYER's IP and must never be used. A configured non-loopback destination stays authoritative. Keep the destination's port and query verbatim: in particular, never rebuild, log or expose an admission ticket.
/proc/babylon_session_log_lineOne record format for the standalone lobby and both world builds. JSON escapes player text, so names and refusal reasons cannot create forged log lines. Never pass tickets or URLs here.
