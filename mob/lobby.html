Vars

announcedThe text each live message (by key) was last drawn with its role: see announce().
last_retryHow the player was last sent to a world ("join", "play" or "edit"): a notice that sends them back says which button to press (lobby_retry_notice). Empty on a fresh mob (neutral wording).
map_buildsMap catalog ids from the last list, with their build ("babylon" or "station").
map_namesMap catalog ids from the last list, with their names.
notice_alertThe notice is a problem (role alert, like the other errors on the page), not a confirmation.
respondedThe page request the current action answered (see respond()).
sent_previewsMap preview images already sent to this client with browse_rsc.
stalled_requestThis player's request that timed out and still runs: until it finishes, no new one is started (the 5 s refresh would pile them up while the supervisor is stalled).
tutorial_cardsTutorials from the last list of the Tutorials tab, by id.

Procs

announceThe role attribute of a live message the first time it is drawn with this text. The poll replaces the whole page whenever anything on it changes, and a redrawn role='alert' can be announced again; later redraws leave the role out, so a message is announced once.
discord_barDiscord link state, requirements and the link/unlink/invite buttons.
join_worldAsks the supervisor for a ticket until the world runs, then sends the player there. A dialog's request is answered after the first reply; later problems become the page notice. A tutorial passes its own loading stage, and how it is tried again (retry, see lobby_retry_notice).
map_previewThe preview image of a catalog map, sent to the client once; null without one.
respondAnswers a page request (lobbyResult in lobby.js: errors stay in the open dialog). Without a request (a plain link) the answer becomes the page notice.
set_noticeThe page notice; alert for a problem, so it is announced like the page's other errors.
tutorial_listThe tutorials for the page: list("tutorials" = items) or list("error" = text).
world_cardOne world in the list. Everything from the supervisor is encoded for where it lands: text and attributes with html_encode, link parameters with url_encode, numbers as numbers.
world_settingsThe create/edit fields of a payload, checked as the supervisor checks them. Returns the clean payload for the supervisor, or an error text.
