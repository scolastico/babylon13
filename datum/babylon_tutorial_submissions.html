babylon_tutorial_submissions
/datum/babylon_tutorial_submissions

The world's tutorial submissions and save backs (one at a time).

Vars

busy_ckeyThe ckey whose submission or save back runs now, else null.
call_typeThe request type (tests use one that answers late).
check_timeoutHow long the world waits for the cooldown check, and for the supervisor's copy of a snapshot.
cooldown_hoursThe supervisor's cooldown between submissions (hours), as its last check said; null before.

Procs

beginReserves the world's one snapshot slot for ckey. FALSE while another runs.
checkThe supervisor's cooldown for ckey: list("ok", "wait_seconds") or list("ok" = FALSE, "error").
discard_snapshotDeletes a tutorial snapshot once the supervisor answered (it has its own copy, or none). The supervisor deletes it too; one left behind is marked and never a checkpoint (persistence.dm).
requestAsks the supervisor (tests replace this to answer themselves).
save_backSaves the edit world back to its pending tutorial (after begin()). list("ok", "text").
submission_answeredThe supervisor answered a submission (in time or late): the snapshot goes, and the owner's panel asks for the cooldown again (it started if the submission went through).
submitSubmits the world as a tutorial (after begin()). list("ok", "text") for the panel.
take_snapshotWrites the tutorial snapshot: list("ok", "generation") or list("error").
