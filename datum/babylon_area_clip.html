babylon_area_clip
/datum/babylon_area_clip

Vars

extrasClip tag => list("fields" = settings (babylon_area_capture_settings), "reagents" = list(list(type, volume)), "contents" = nested entries).
from_storageMade from stored data (babylon_area_clip_from_data): settings are applied only for the fields the save engine keeps for the object's type.
originThe south-west corner it was copied from: list(x, y, z).
skipped_mobsWhat the copy left out: mobs, protected objects, protected tiles, turfs it can't build.
tilesOne entry per tile, column by column from the south-west corner: list("turf" = "path{vars}", "objects" = list("path{vars}", ...), "space" = TRUE/FALSE).
tutorialTutorial objects: list("dx", "dy", "type", "id", "settings", "dir", "pixel_x", "pixel_y", "npc").

Procs

entryThe tile entry at an offset from the south-west corner.
to_dataThe clip as JSON-safe data. Tutorial objects are left out: a stored room never carries them (the room's own tutorial objects stay where they are when it is pasted). Tiles are stored as a palette of distinct tile entries plus one palette index per tile (like a map's keys), so a room of plain floors costs one entry.
